# Factor Lab · 技术因子回测工作台

React + TypeScript / FastAPI + TA-Lib 的本地中文日频研究页面。直接读取 `feathers` 中的 7 个 Feather 矩阵，不上传行情数据，不依赖在线行情或外部字体服务。

## 启动（Windows PowerShell）

建议 Python 3.11–3.14、Node.js 22.12+。已在 Python 3.14 与 Node.js 24 验证。TA-Lib 0.6.8+ 提供包含底层 C 库的常见平台二进制 wheel，无需手动编译。

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
npm install --prefix .\frontend
```

两个终端分别运行：

```powershell
# 终端 1：仓库根目录
.\.venv\Scripts\python.exe -m uvicorn backend.main:app --host 127.0.0.1 --port 8000
```

```powershell
# 终端 2：仓库根目录
npm run dev --prefix .\frontend
```

访问 <http://127.0.0.1:5173>；API 文档：<http://127.0.0.1:8000/docs>。Vite 将 `/api` 请求代理给后端，不需要开启跨域。两项服务默认仅监听本机；不要将无鉴权的研究服务直接暴露到公网。

## 功能

- 12 种可调参数策略，按趋势跟踪、均值回归、动量和波动突破分类，指标均使用真实 TA-Lib。
  - 趋势：MACD、双 SMA 均线、双 EMA 均线、ADX + DI。
  - 均值回归：RSI、布林带、KDJ、CCI、威廉指标 WILLR。
  - 动量与突破：ROC、ATR 通道、唐奇安通道。
- 按代码搜索，选择 1–20 只证券；自定义日期、技术参数、初始资金、佣金、滑点、固定卖出税率、前日成交额门槛。
- 策略与买入持有净值、回撤、月度收益、交易统计、首只证券的因子图。
- 全量结果与参数 JSON 下载、交易 CSV 下载、交易方向筛选和分页。
- 数据概览显示文件大小及最后交易日有限值覆盖率；错误明确展示，保留的旧结果会提示。

## 数据约定

仓库根目录下的 `feathers`（已加入 Git 忽略）包含：

| 文件 | 内容 |
| --- | --- |
| `open.feather` / `high.feather` / `low.feather` / `close.feather` | 日频原始价格 |
| `amt.feather` | 日成交额（假定单位为元） |
| `num_trades.feather` | 日成交笔数 |
| `cumadj.feather` | 乘法累积复权因子 |

首列必须为升序唯一的 `date`，其余为证券代码列，各文件的日期、证券列及顺序必须一致。当前文件覆盖 2020-01-02 至 2026-10-16，共 1,643 日、5,451 只证券。启动会验证矩阵对齐；回测按列读取选中证券，并缓存最近 8 个证券池。数据在服务运行期间视为不可变，更新文件后应重启后端。

`num_trades` 在最后一天存在缺失，不能用它判断该日开盘是否可成交。KDJ、CCI、ADX、WILLR、ATR 和唐奇安使用 `high`、`low`、`close`，三者按同一 `cumadj` 同步复权；其余策略只需要复权收盘价。撮合使用 `open`，流动性门槛使用前日 `amt`，`num_trades` 只用于数据检查。没有真实成交量 `volume`，不把成交额或成交笔数冒充成交量来计算 OBV、MFI 等指标。

## 回测模型与限制

1. **信号时点**：使用所选区间之前的所有可用历史预热。T 日收盘计算目标状态，在下一交易日有效开盘执行。首个回测日可以响应前一交易日信号，不在区间末尾偷用未来数据。
2. **技术策略**：
   - MACD：DIF > DEA 持有，否则空仓；图中柱值为 `2 × (DIF − DEA)`。
   - SMA：短期 SMA > 长期 SMA 持有，否则空仓。
   - RSI：低于买入阈值建仓，高于卖出阈值退出，中间保持原状态。
   - 布林带：收盘低于下轨建仓，回归中轨及以上退出。
   - EMA：短期 EMA > 长期 EMA 持有，否则空仓，复用短/长周期参数。
   - KDJ：TA-Lib `STOCH`，默认随机周期 9，K/D 各用 3 期简单均线平滑，`J = 3K − 2D`；**不是国内递归 SMA 平滑的 KDJ**。K > D 且 K < 买入阈值（默认 30）建仓，K < D 或 K > 卖出阈值（默认 80）退出。
   - CCI：默认 14 期；CCI < 买入阈值（默认 -100）建仓，CCI > 卖出阈值（默认 100）退出。
   - ADX：默认 14 期；ADX ≥ 强度阈值（默认 25）且 +DI > −DI 持有，否则空仓。
   - WILLR：默认 14 期；低于买入阈值（默认 -80）建仓，高于卖出阈值（默认 -20）退出。
   - ROC：默认 12 期；`100 × (收盘价 / N 个有效观测前的收盘价 − 1)` 高于阈值（默认 0）持有，否则空仓。阈值单位为百分数，5 表示 5%。
   - ATR 通道：默认 14 期 ATR、20 期 EMA、2 倍 ATR；收盘突破 `EMA + 倍数 × ATR` 建仓，跌破 `EMA − 倍数 × ATR` 退出，中间保持原状态。
   - 唐奇安：默认突破周期 N=20、退出周期 M=10（M ≤ N）；收盘突破**此前 N 个有效观测**的最高价建仓，跌破**此前 M 个有效观测**的最低价退出。TA-Lib `MAX` / `MIN` 计算的通道再向后移动一个有效观测，明确排除当前交易日；不能直接用包含当日最高价的上轨检测收盘突破。
3. **复权**：`原始价格 × 当日 cumadj / 该证券首个有效 cumadj`，不采用未来末日复权锚点。假定数据提供的 `cumadj` 是正确的乘法累计因子；成交价、数量均为复权价格与复权单位，**不是原始价格和真实股数**。公司行为收益由复权因子表达，不另行计分红。
4. **组合**：多头或空仓，每只证券分配等额初始资金、独立子账户复投，不跨证券再平衡，不放大杠杆。期末持仓按收盘估值，不强制卖出。基准为同证券池、等初始资金、无费用的买入持有，不是市场指数。
5. **交易费用**：佣金双边，税率仅卖出，滑点体现在买入价上浮/卖出价下浮；`1 bp = 0.01%`。固定费率不追溯历史税制，不含最低佣金。费用统计不包含隐含在成交价中的滑点。
6. **流动性**：仅以**前一交易日**成交额筛选新开仓，0 表示不限制，缺失不达标；平仓不受门槛限制。不能用当日完整成交额来决定当日开盘成交。
7. **缺失行情**：TA-Lib 按有效价格的观测序列计算，缺失日保留上个目标状态但不生成新信号。需要高低价的策略只使用高低收盘价均有限且 `0 < low ≤ close ≤ high` 的观测，不使用前向/后向填充来伪造高低价，并明确提示被跳过的行情数。开盘/复权因子无效则不交易；缺失收盘使用当日有效开盘或上次价格估值。没有有效行情的证券子账户保留现金。
8. **统计**：年化收益按 `净值^(252/交易日数)-1`；夏普基于零无风险利率、日收益样本标准差；回撤包括初始净值 1；胜率只统计已平仓、扣双边费用后的盈亏。无波动夏普、无平仓胜率返回空值，不伪造为 0。超额收益为策略区间收益减基准区间收益，非风险调整 alpha。
9. **非实盘撮合**：可交易碎份额；未实现整手、涨跌停、真实停牌、退市处置、市场冲击、容量限制。仅靠日频数据不能验证开盘成交可得性，不能据此直接实盘。历史证券池还可能存在幸存者偏差。

仅供量化研究，不构成投资建议。
