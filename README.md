# Factor Lab · 技术因子回测工作台

React + TypeScript / FastAPI + TA-Lib 的本地中文日频研究页面。直接读取 `feathers` 中的 7 个 Feather 矩阵，不上传行情数据，不依赖在线行情或外部字体服务。首次使用某个指数股票池、或主动同步名单时，会下载中证指数官方成分股文件；已有快照可离线复用。

## 启动（Windows PowerShell）

建议 Python 3.11–3.14、Node.js 22.12+。已在 Python 3.14 与 Node.js 24 验证。TA-Lib 0.6.8+ 提供包含底层 C 库的常见平台二进制 wheel，无需手动编译。

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
npm install --prefix .\frontend
```

两个终端分别运行：

```powershell
# 终端 1：仓库根目录
.\.venv\Scripts\python.exe -m uvicorn backend.main:app --host 127.0.0.1 --port 8000
```

```powershell
# 终端 2：仓库根目录
npm run dev --prefix .\frontend
```

访问 <http://127.0.0.1:5173>；API 文档：<http://127.0.0.1:8000/docs>。Vite 将 `/api` 请求代理给后端，不需要开启跨域。两项服务默认仅监听本机；不要将无鉴权的研究服务直接暴露到公网。

## 功能

- 12 种可调参数策略，按趋势跟踪、均值回归、动量和波动突破分类，指标均使用真实 TA-Lib。
  - 趋势：MACD、双 SMA 均线、双 EMA 均线、ADX + DI。
  - 均值回归：RSI、布林带、KDJ、CCI、威廉指标 WILLR。
  - 动量与突破：ROC、ATR 通道、唐奇安通道。
- 默认使用沪深300股票池，可切换中证500、中证1000、上证50；使用官方成分股与本地行情的**全部匹配证券**，不截取前 20 只。另保留按代码搜索的 1–20 只手动证券池。
- 可视化策略设计器：组合 TA-Lib 指标、数值阈值及交叉条件，定义 AND / OR 买卖规则，支持本地保存、修改、删除和应用。
- 自定义日期、技术参数、初始资金、佣金、滑点、固定卖出税率、前日成交额门槛。
- 策略与买入持有净值、回撤、月度收益、交易统计、首只证券的因子图。
- 全量结果与参数 JSON 下载、交易 CSV 下载、交易方向筛选和分页。
- 数据概览显示文件大小及最后交易日有限值覆盖率；错误明确展示，保留的旧结果会提示。
- Dashboard 一次运行全部 12 种内置策略，加上当前应用的 1 条自定义策略（如有）：净值/回撤叠图、可切换指标柱图、收益风险散点、月度收益热力图，以及 14 项完整指标的分类筛选与排序。
- 每种策略进行 8 项计算验证；支持查看检查明细、跳转单策略、导出全指标 CSV 和完整验证报告 JSON。
- 独立「因子评价」页面：复用已有技术指标，提供横截面 IC / Rank IC、ICIR、多周期衰减、非重叠分层收益、覆盖率和因子 Rank 相关矩阵，支持参数编辑及 CSV / JSON 导出。
- 「因子挖掘 Agent」：参考 RD-Agent 的假设—实验—反馈闭环，读取本地 Qlib 历史股票池，支持确定性本地配方与可选 Azure LLM 提案；展示全部候选、晋升轨迹、收益风险对比和冻结测试。

## 因子评价：横截面单因子研究

打开 <http://127.0.0.1:5173/#evaluation>，或点击桌面 / 手机导航的 **因子评价**。

1. 股票池、日期、成交额门槛沿用策略页，通过「编辑股票池 / 日期」修改；买卖规则、资金和交易成本不参与因子统计。默认使用完整沪深300匹配池，最少截面样本数为 10；使用较小手动池时应同步调低样本数与分层数（最少 3 个样本）。
2. 默认评价 RSI、ROC、CCI、MACD 柱值、ADX、ATR。可添加全部 22 种现有指标，或导入当前应用的自定义策略中出现的指标（不是买卖条件），最多同时评价 24 个参数化因子。点击因子标签编辑对应参数，同一指标可以添加不同参数，但相同参数不允许重复。
3. 设置主评价周期、分层数、最少截面样本数及衰减分析周期（1 / 5 / 10 / 20 / 40 / 60 个交易日），运行评价。主周期必须包含在衰减周期内；API 支持 1–60 日。日期至少覆盖「主周期 + 2」个实际交易日。
4. 查看可排序因子全景、IC / Rank IC 时间序列、多周期统计明细、分层净值与平均收益、高低层差、覆盖率与有效样本，以及因子相关性矩阵。负向相关如实显示，不按样本内表现翻转方向，也不输出自动优劣评分。
5. 「指标 CSV」导出全部因子的主周期统计，收益和覆盖率以小数表示，空值留空；「完整 JSON」保留解析后的股票池快照、参数、所有周期统计、逐日 IC、分层明细和研究口径。报告在页面会话内保留，切换页面不会丢失成功报告；刷新页面后清空，可下载 JSON 归档。修改配置会提示旧报告，需要重新计算；请求失败不覆盖已有结果。

### 计算口径

- 指标直接调用策略设计器所用的 TA-Lib 指标实现，使用评价开始前的全部历史预热。T 日收盘生成因子，H 日标签为 **复权开盘价(T+1+H) / 复权开盘价(T+1) − 1**，避免用无法在收盘后成交的 T 日收盘价作入场价。不会读取结束日期之后的数据补全尾部标签。
- 相对价格模式下，SMA / EMA / 布林 / 唐奇安轨道使用「指标 / 复权收盘 − 1」，MACD / ATR 使用「指标 / 复权收盘」，其他无量纲指标不变。收盘价保留原始复权值，并提示跨证券可比性风险；原始模式的价格型指标亦有明确提示。
- 覆盖率 = 有效因子观测数 /（证券数 × 区间交易日数），含指标预热不足及缺失观测。成交额门槛使用信号日成交额（即下一日执行时已知的前日成交额）。
- IC 为每日因子与未来标签的 Pearson 相关；Rank IC 为共同有效样本平均秩的 Spearman 相关。截面样本数不足、因子或标签常数时记空值。ICIR / Rank ICIR 使用均值除以样本标准差，**不年化**；标准差为零或有效日期不足时留空。正比率为有效相关值严格大于零的日期比例。
- 每 H 日用完整未来标签的共同样本按因子从低到高分层，平均秩分配到等分位区间；不拆分并列值，导致空层或样本不足则整期跳过。层内等权，层净值逐期复利；高低层差固定为最高层减最低层，累计差**算术累加**，不是可交易多空组合净值。跳过期不补收益、不改调仓日程。
- 单调性为层序与各层平均持有期收益的 Spearman 相关。因子相关性矩阵为共同有效样本上的逐日截面 Rank 相关均值，不是 IC 时间序列之间的相关。

**这是探索性因子统计，不是实盘收益或显著性认证。** 多日逐日标签重叠，不能把日期数当作独立样本。未来开盘缺失 / 退市样本的完整标签筛选有选择偏差；指数使用静态成分股快照，存在成分股前视及幸存者偏差；没有行业、市值中性化，也未扣交易、借券和冲击成本。没有历史成分股、行业、市值、成交量数据，因此不伪造相关能力。

接口：`POST /api/factors/evaluate`。请求包括 `config`（现有 `/api/backtest` 配置）、`factors`（现有指标规格）、`horizons`、`primary_horizon`、`groups`、`min_samples`、`normalization`（`relative_price` 或 `raw`）。响应包括 `request` 参数快照、`universe`、`period`、`results`、`correlations`、`elapsed_ms` 和 `warnings`。不新增依赖、不上传行情。

## Dashboard：全策略验证与对比

打开 <http://127.0.0.1:5173/#dashboard>，或点击侧栏 / 手机导航的 **Dashboard**。

1. 点击「编辑回测配置」，在原有策略页设置证券池、日期、成本、流动性门槛，以及各策略的技术参数。所有参数保留在当前页面会话中；刷新页面恢复默认值。
2. 返回 Dashboard，点击「运行全部策略并验证」。全部策略沿用相同证券池、初始资金、日期、成本及筛选条件，每种策略使用已设置的对应参数，不会自动优化或挑选参数。
3. 在「全局概览」中点击策略图例来显示/隐藏曲线，并切换净值、回撤及任一绩效指标柱图；图例筛选不改变指标表和导出的完整报告。
4. 「全部指标对比」包含累计收益、年化收益、基准收益、超额收益、最大回撤、夏普、年化波动、已平仓胜率、成交笔数、已平仓笔数、费用、期末资产、平均仓位和期末持仓证券数。点击表头排序，空值始终排在最后；横向滚动可看全表。
5. 「策略验证报告」显示各项检查、实际参数及数据/模型提示。可打开单策略明细；系统会使用报告中的参数快照重新运行，而不是套用之后修改的参数。

当前应用的自定义策略作为第 13 个候选一起验证，**不是自动运行所有已保存的自定义策略**。如需比较另一条，先在策略设计器中载入并应用。完整指数池及历史前缀重放可能需要几十秒，界面在计算完成前保留上一次报告。

批量接口为 `POST /api/compare`，请求字段与 `/api/backtest` 相同，但必须保证所有策略的参数关系均有效，包括短周期 < 长周期、唐奇安退出周期 ≤ 突破周期。批量 API 复用同一个回测引擎，不另写收益计算路径。

每种策略的 8 项检查：

| 检查 | 内容 |
| --- | --- |
| 交易日与区间对齐 | 与实际交易日历逐日核对，所有策略采用同一区间 |
| 数值与仓位边界 | 拒绝非有限资金/指标、非正净值或越界仓位；允许夏普/胜率的合法空值 |
| 收益风险指标复算 | 从逐日净值与交易明细复算收益、回撤、夏普、波动、胜率、费用等 |
| 交易账本与资产守恒 | 核对买卖顺序、数量/金额、佣税、已实现盈亏、剩余现金和期末持仓估值 |
| 月度收益一致性 | 按自然月重新计算收益，保留不足整月的首尾月份 |
| 买入持有基准一致 | 所有策略使用同一证券池、同一日历上的相同基准 |
| 历史前缀重放 | 截断到区间中部、保留此前预热历史并重新回测，比较原结果此前的净值、交易和首只证券技术指标 |
| 有效交易样本 | 明确标注成交/平仓样本数；没有交易不标记为成功 |

前缀检查需要至少 3 个实际交易日且前半段有可用开盘价，否则明确标记「未执行」。任一检查失败则标记「验证失败」、记录后端日志，并从图表和最优摘要中排除；指标表仍保留记录。有未执行检查则标记「需关注」，不冒充通过。数值比较采用相对容差 `1e-9`、绝对容差 `1e-7`；账本现金浮点误差还允许不超过初始资金的 `1e-9`。

**验证通过仅表示本次计算一致性通过，并非盈利能力、样本外稳健性或实盘可交易性认证。** 单次前缀重放不是全面的无未来数据泄漏证明；历史最优策略还存在多重比较和过拟合风险。摘要只比较有交易且未验证失败的策略，不把现金空仓的零收益当作最优策略。

结果与参数一起保留为报告快照。修改配置后会明确提示需要重新比较；计算中或请求失败时不覆盖上一次报告。CSV 导出全部 14 项原始数值（收益率用小数，空值留空），JSON 包括配置、曲线、月收益、验证结果及数据提示；报告不会上传到外部服务。

## 如何自定义策略

打开 <http://127.0.0.1:5173/#designer> 或点击「策略设计」：

1. 从「MACD 金叉 + RSI 过滤」示例开始，输入策略名称。
2. 分别配置买入、卖出条件，每组支持 1–6 条，选择「全部满足 AND」或「任一满足 OR」。每条规则由左侧指标、比较方式、右侧阈值或另一个指标组成，左右指标参数独立。
3. 支持收盘价、SMA、EMA、RSI、MACD DIF/DEA/柱值、K/D/J、CCI、ADX、±DI、WILLR、ROC、ATR、布林三轨和唐奇安上下轨；没有 volume，因此不提供 OBV/MFI。
4. 比较方式包括 `>`、`>=`、`<`、`<=`、向上穿越、向下穿越。例如买入设为「DIF 向上穿越 DEA **且** RSI < 70」，卖出设为「DIF 向下穿越 DEA **或** 收盘价 < SMA(20)」。
5. 点击「保存策略」持久化，或「保存并应用到回测」返回回测页；选择股票池和日期，运行回测。技术因子页按单位分面展示价格、MACD、RSI 等，避免不同量纲混在同一纵轴。
6. 重新进入设计器可继续编辑当前已应用的规则，或从保存列表载入另一条。再次保存会更新该记录；点击「新建 / 载入示例」创建新记录。已应用规则、已生成报告均为独立快照，编辑或删除保存记录不会改写旧报告。

同日买卖条件同时成立时**卖出优先**；没有触发则保持状态，只做多 / 空仓。每个条件仅在所需指标有效时参与，缺失条件视为不满足；OR 组的其他有效条件仍能触发。金叉/死叉要求当前及紧邻前一交易日两侧值均有效，首次预热完成、或缺失后首次恢复不算交叉。信号仍在 T 日收盘形成，下一交易日开盘执行，不支持任意 Python 表达式或 `eval`。

策略 CRUD 接口：`GET /api/strategies`、`POST /api/strategies`、`PUT /api/strategies/{UUID}`、`DELETE /api/strategies/{UUID}`。创建与更新的请求体是 `{name, entry: {mode, rules}, exit: {mode, rules}}`；完整字段和取值范围见 `/docs`。回测传 `strategy: "custom"` 和完整 `custom_strategy`，而非读取一个可变的策略 ID。

## 指数股票池与快照

- 默认 **沪深300（000300）**；备选 **中证500（000905）**、**中证1000（000852）**、**上证50（000016）**，也可切换手动池。
- 名单固定来源为中证指数官方 XLS：`https://oss-ch.csindex.com.cn/static/html/csindex/public/uploads/file/autofile/cons/{指数代码}cons.xls`。严格校验列名、指数代码、数量、日期、交易所及代码唯一性；按 `.SH` / `.SZ` 与本地矩阵匹配。页面显示文件中的真实快照日期、获取时间、来源和匹配数，缺失名单记录于结果 `universe.missing`，不伪造成分股。
- `GET /api/universes` 返回缓存状态；`POST /api/universes/{hs300|zz500|zz1000|sz50}/sync` 主动同步。无缓存时回测自动获取；已有缓存时不联网，除非主动同步。同步失败明确报错且保留旧缓存，不悄悄替换数据源或用手动样本充当完整指数。
- 回测指定 `universe`；省略 `universe` 且未传 `symbols` 时默认沪深300。为兼容旧接口，显式传 `symbols`、未传 `universe` 时仍解释为手动池。指数池的 `symbols` 以官方名单解析结果为准，不接受传入数组替换指数。
- 每个快照按成分列表和文件快照日期生成 SHA256 `universe_version`；回测配置固定版本和实际参与的证券，报告另含来源、日期、匹配 / 缺失明细。打开旧报告时按存档版本重放；指定版本不存在会报错，绝不改用最新名单。JSON 报告含完整规则和名单；迁移机器时需同时备份本地数据库及相同 Feather 数据，数据库不在代码仓库内。
- 自定义策略和版本化指数快照保存于 `.local/research.sqlite3`（已 Git 忽略）。普通界面参数仍是当前页面会话状态，刷新后恢复默认值，保存的策略和名单不丢失。

**重要：这里使用最新成分股的静态快照，不是历史时点成分股。** 将今天的成分股用于历史回测，会引入幸存者及成分股前视偏差，即使计算验证全部通过也不会消除。股票池只决定参与证券；基准仍为同池等初始资金买入持有，**不是沪深300等官方指数收益**。需要无此类偏差的研究时，应另行引入按生效日期维护的历史成分数据。

## 数据约定

仓库根目录下的 `feathers`（已加入 Git 忽略）包含：

| 文件 | 内容 |
| --- | --- |
| `open.feather` / `high.feather` / `low.feather` / `close.feather` | 日频原始价格 |
| `amt.feather` | 日成交额（假定单位为元） |
| `num_trades.feather` | 日成交笔数 |
| `cumadj.feather` | 乘法累积复权因子 |

首列必须为升序唯一的 `date`，其余为证券代码列，各文件的日期、证券列及顺序必须一致。当前文件覆盖 2020-01-02 至 2026-10-16，共 1,643 日、5,451 只证券。启动会验证矩阵对齐；回测按列读取选中证券，并缓存最近 8 个证券池。数据在服务运行期间视为不可变，更新文件后应重启后端。

`num_trades` 在最后一天存在缺失，不能用它判断该日开盘是否可成交。KDJ、CCI、ADX、WILLR、ATR 和唐奇安使用 `high`、`low`、`close`，三者按同一 `cumadj` 同步复权；其余策略只需要复权收盘价。撮合使用 `open`，流动性门槛使用前日 `amt`，`num_trades` 只用于数据检查。没有真实成交量 `volume`，不把成交额或成交笔数冒充成交量来计算 OBV、MFI 等指标。

## 回测模型与限制

1. **信号时点**：使用所选区间之前的所有可用历史预热。T 日收盘计算目标状态，在下一交易日有效开盘执行。首个回测日可以响应前一交易日信号，不在区间末尾偷用未来数据。
2. **技术策略**：
   - MACD：DIF > DEA 持有，否则空仓；图中柱值为 `2 × (DIF − DEA)`。
   - SMA：短期 SMA > 长期 SMA 持有，否则空仓。
   - RSI：低于买入阈值建仓，高于卖出阈值退出，中间保持原状态。
   - 布林带：收盘低于下轨建仓，回归中轨及以上退出。
   - EMA：短期 EMA > 长期 EMA 持有，否则空仓，复用短/长周期参数。
   - KDJ：TA-Lib `STOCH`，默认随机周期 9，K/D 各用 3 期简单均线平滑，`J = 3K − 2D`；**不是国内递归 SMA 平滑的 KDJ**。K > D 且 K < 买入阈值（默认 30）建仓，K < D 或 K > 卖出阈值（默认 80）退出。
   - CCI：默认 14 期；CCI < 买入阈值（默认 -100）建仓，CCI > 卖出阈值（默认 100）退出。
   - ADX：默认 14 期；ADX ≥ 强度阈值（默认 25）且 +DI > −DI 持有，否则空仓。
   - WILLR：默认 14 期；低于买入阈值（默认 -80）建仓，高于卖出阈值（默认 -20）退出。
   - ROC：默认 12 期；`100 × (收盘价 / N 个有效观测前的收盘价 − 1)` 高于阈值（默认 0）持有，否则空仓。阈值单位为百分数，5 表示 5%。
   - ATR 通道：默认 14 期 ATR、20 期 EMA、2 倍 ATR；收盘突破 `EMA + 倍数 × ATR` 建仓，跌破 `EMA − 倍数 × ATR` 退出，中间保持原状态。
   - 唐奇安：默认突破周期 N=20、退出周期 M=10（M ≤ N）；收盘突破**此前 N 个有效观测**的最高价建仓，跌破**此前 M 个有效观测**的最低价退出。TA-Lib `MAX` / `MIN` 计算的通道再向后移动一个有效观测，明确排除当前交易日；不能直接用包含当日最高价的上轨检测收盘突破。
3. **复权**：`原始价格 × 当日 cumadj / 该证券首个有效 cumadj`，不采用未来末日复权锚点。假定数据提供的 `cumadj` 是正确的乘法累计因子；成交价、数量均为复权价格与复权单位，**不是原始价格和真实股数**。公司行为收益由复权因子表达，不另行计分红。
4. **组合**：多头或空仓，每只证券分配等额初始资金、独立子账户复投，不跨证券再平衡，不放大杠杆。期末持仓按收盘估值，不强制卖出。基准为同证券池、等初始资金、无费用的买入持有，不是市场指数。
5. **交易费用**：佣金双边，税率仅卖出，滑点体现在买入价上浮/卖出价下浮；`1 bp = 0.01%`。固定费率不追溯历史税制，不含最低佣金。费用统计不包含隐含在成交价中的滑点。
6. **流动性**：仅以**前一交易日**成交额筛选新开仓，0 表示不限制，缺失不达标；平仓不受门槛限制。不能用当日完整成交额来决定当日开盘成交。
7. **缺失行情**：TA-Lib 按有效价格的观测序列计算，缺失日保留上个目标状态但不生成新信号。需要高低价的策略只使用高低收盘价均有限且 `0 < low ≤ close ≤ high` 的观测，不使用前向/后向填充来伪造高低价，并明确提示被跳过的行情数。开盘/复权因子无效则不交易；缺失收盘使用当日有效开盘或上次价格估值。没有有效行情的证券子账户保留现金。
8. **统计**：年化收益按 `净值^(252/交易日数)-1`；夏普基于零无风险利率、日收益样本标准差；回撤包括初始净值 1；胜率只统计已平仓、扣双边费用后的盈亏。无波动夏普、无平仓胜率返回空值，不伪造为 0。超额收益为策略区间收益减基准区间收益，非风险调整 alpha。
9. **非实盘撮合**：可交易碎份额；未实现整手、涨跌停、真实停牌、退市处置、市场冲击、容量限制。仅靠日频数据不能验证开盘成交可得性，不能据此直接实盘。历史证券池还可能存在幸存者偏差。

仅供量化研究，不构成投资建议。
